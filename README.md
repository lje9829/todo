# My Weekly Planner

월~일 7칸(06–12 / 12–18 / 18–00 시간대별 할 일)과 메모 1칸으로 구성된 개인 위클리 플래너입니다. 각 할 일은 개별 체크박스로 완료 처리할 수 있습니다.

## GitHub Pages 배포
1. 새 GitHub 저장소를 만들고 ZIP 압축을 해제합니다.
2. `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`로 지정하고 **Save**를 누릅니다.
5. 배포 완료 후 `https://사용자명.github.io/저장소명/`에 접속합니다.

별도 설치나 서버는 필요하지 않습니다. 작성한 내용은 해당 브라우저의 localStorage에 저장되며 다른 기기와 동기화되지 않습니다. 사이트 데이터를 삭제하면 사라질 수 있으므로 앱의 백업 기능을 활용하세요. 로컬 HTML과 GitHub Pages는 저장 영역이 서로 다릅니다.
